## Topic

Project monitoring, control, risk, quality, change management, closure and acceptance criteria; plus web usability, user-centred design, usability evaluation, and prototype review.

## What I should learn

- Track project performance using KPIs and status tools.
- Use a Change Control Board and change log to assess proposed changes.
- Identify, assess, respond to, monitor, and communicate project risks.
- Define closure activities and measurable acceptance criteria.
- Apply recognised usability principles, especially Nielsen's heuristics, to a prototype.
- Plan and conduct usability evaluation and testing.
